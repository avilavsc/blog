## 1. Material

### 1.1 Mapa diário FCC (5 eixos)

| Eixo | Pergunta-âncora | Erro clássico |
|------|-----------------|---------------|
| **Crase** | Há preposição **a** + artigo **a(s)**? | Crase em masculino, verbo, indefinido |
| **Concordância verbal** | Qual é o **sujeito** real? | Concordar com adjunto / objeto |
| **Concordância nominal** | O adjetivo/pronome concorda com **quem**? | *meio/meia*, *anexo/anexa*, *é necessário/a* |
| **Regência** | O verbo/nome exige **qual** preposição neste sentido? | Trocar sentido e manter a mesma prep. |
| **Pontuação + conectivos** | Sujeito×verbo intactos? Valor do conectivo certo? | Vírgula SV; *embora* no lugar de *porque* |

Flash de prova: **sujeito → sentido do verbo → preposição → gênero do termo seguinte → vírgulas**.

### 1.2 Crase — cartão de revisão

**Crase** = preposição **a** + artigo feminino **a/as** (ou *àquele/àquela/àquilo*).

**Teste:** masculinize. Se surgir **ao/aos**, no feminino há **à/às**.

| Obrigatória (âncoras) | Proibida (eliminação) |
|-----------------------|------------------------|
| *obedeceu **às** normas* | Antes de **masculino**: *a processo* |
| Locuções femininas: *à noite, às vezes, à medida que* | Antes de **verbo**: *a estudar* |
| Horas: *às 14 horas* | Pronome pessoal: *a ela* |
| *àquele / àquela / àquilo* | Indefinido: *a nenhuma* / *a uma* |
| *à moda de / à maneira de* | Palavras repetidas: *cara a cara* |
| *voltou **à** casa da tia* (com determinante) | *foi a casa* (própria, sem artigo) |

**Facultativa / atenção:** *até a / até à*; possessivo feminino quando artigo cabe (*referiu-se à sua petição*).  
**Cidades:** *foi a Porto Alegre* (sem artigo habitual); *foi **à** Bahia* (com artigo no uso).

**Cartão:** crase exige **dois “a”**. Se só preposição ou só artigo → sem crase.

### 1.3 Concordância verbal — cartão

1. Ache o **sujeito** antes do verbo (pode estar invertido/distante).  
2. Sujeito composto anteposto → plural.  
3. *Haver* (= existir) e *fazer* (tempo) → **sempre singular**: *Houve atrasos* · *Faz dois anos*.  
4. Partitivos / percentuais / *maioria*: singular (com o partitivo) **ou** plural (com o especificado).  
5. *Mais de um* → singular. *Cerca de N* (pluralidade) → plural.  
6. *Que* → verbo com o **antecedente**. *Quem* → clássico 3ª sg.  
7. **Se** apassivador: *Vendem-se certidões* (concorda com paciente). **Se** indeterminador: *Precisa-se de analistas* (singular + prep.).  
8. Sujeito oracional → principal no singular: *Convém que…* / *É necessário analisar…*.  
9. *Deve haver* (não *devem haver* no sentido existir).  
10. *Parece haver dúvidas* (não *parecem haver*).

### 1.4 Concordância nominal — cartão

| Caso | Forma segura |
|------|--------------|
| *É necessário atenção* (sem artigo) | invariável no masculino |
| *É necessária **a** atenção* (com artigo) | concorda |
| *proibida **a** entrada* | concorda com o substantivo |
| *anexo(s)/anexa(s)* | concorda com o que se anexa |
| *em anexo* | **invariável** |
| *meio cansada* | *meio* (= um pouco) invariável |
| *meias verdades* | *meia* (= metade) varia |
| *bastante(s)* | adjetivo → varia; advérbio → invariável |
| *mesmo / próprio* | em geral concordam (*elas mesmas*; *elas próprias*) |
| *é proibido / é bom / é preciso* + substantivo sem artigo | forma masculina |

### 1.5 Regência — cartão

| Verbo / nome | Preposição cobrável | Pegadinha |
|--------------|---------------------|-----------|
| *assistir* (= ver) | **a** | *assistir o* ❌ |
| *aspirar* (= almejar) | **a** | *aspirar o cargo* ❌ neste sentido |
| *visar* (= almejar) | **a** | *visar o* (no sentido mirar/rubricar pode ser TD) |
| *preferir X **a** Y* | **a** | *preferir do que / mais…* ❌ |
| *implicar* (= acarretar) | TD (sem *em*) | *implicar em* ❌ (padrão culto clássico) |
| *obedecer / desobedecer* | **a** | |
| *chegar **a*** | **a** | *chegar em* (coloquial; FCC costuma cobrar *a*) |
| *simpatizar / antipatizar* | **com** | *simpatizar a* ❌ |
| *lembrar / esquecer* | TD **ou** *de* com pronominal | misturar esquemas |
| *informar* | algo **a** alguém / alguém **de** algo | |
| *responsável* | **por** | |
| *compatível* | **com** | *compatível a* ❌ |
| *apto / favorável / referente* | **a** | |
| *acesso* | **a** | *acesso em* ❌ |

### 1.6 Pontuação — cartão

**Não separar:** sujeito×verbo · verbo×OD/OI · verbo de ligação×predicativo · nome×complemento · *que* integrante×oração.

**Intercalação:** precisa **par** de vírgulas: *A norma, quando clara, orienta.*

| Sinal | Uso cobrável |
|-------|--------------|
| **,** | aposto, vocativo, enumeração, adjunto deslocado, adversativa, explicativa |
| **;** | orações longas relacionadas; itens complexos |
| **:** | anunciar explicação / enumeração / citação |
| **—** | destaque / intercalação enfática |
| Restritiva × explicativa | vírgula **muda** o sentido |

### 1.7 Conectivos — valor semântico

| Relação | Preferir | Não trocar por |
|---------|----------|----------------|
| Causa | porque, pois, uma vez que, visto que, porquanto | *embora* |
| Oposição | porém, contudo, entretanto, no entanto, todavia | *uma vez que* |
| Concessão | embora, conquanto, ainda que, mesmo que | *porque* |
| Conclusão | portanto, assim, logo, destarte, desse modo | empilhar três |
| Adição | além disso, ademais, bem como | *contudo* |
| Finalidade | a fim de que, para que | |
| Esclarecimento | isto é, ou seja, por exemplo | |

Drill rápido: *A transparência é necessária. Há dados sensíveis.*  
— com **embora** (concessão) ≠ com **uma vez que** (causa).

### 1.8 Rotina de 20 minutos (semana 11)

| Min | Ação |
|-----|------|
| 0–3 | Abrir 1 cartão (crase **ou** concordância **ou** regência **ou** pontuação/conectivos) |
| 3–12 | Resolver 4–5 itens (treino ou concurso) **sem** olhar gabarito |
| 12–18 | Conferir + anotar no caderno de erros (eixo + motivo) |
| 18–20 | Reescrever **1** frase errada na forma correta |

Meta da semana: girar os 5 eixos ≥1× cada + ≥80 Q totais (todas as matérias).

### 1.9 Anti-lista (o que a FCC arma)

- *à lápis / à ninguém / à uma*  
- *Houveram / Fazem anos* (impessoais no plural)  
- *Devem haver dúvidas*  
- Vírgula entre sujeito e verbo sem intercalação completa  
- *preferir X do que Y*  
- *embora* com valor de causa  
- *isso* sem antecedente na reescrita “clara e correta”

### Gabarito comentado (treino 1–15)

1. **C** — *comparecer a* + feminino determinado → *à audiência*. A indefinido; B verbo; D pessoal; E cidade sem artigo habitual.  
2. **C** — *a lápis* (masculino / instrumento) → sem crase.  
3. **C** — *Deve haver* (impessoal). A/B/D/E quebram impessoalidade.  
4. **B** — passiva sintética; verbo no plural com *certidões*.  
5. **D** — com artigo, *É necessária a…*. A falta acordo; B *anexas*; C *meio*; E *em anexo* invariável.  
6. **D** — *implicar* (= acarretar) TD. A/B falta *a*; C *do que* ❌; E *com*.  
7. **B** — *responsável por* · *à diretoria*.  
8. **C** — vírgula indevida sujeito×verbo.  
9. **C** — *embora* = concessão.  
10. **D** — *visto que* = causa.  
11. **B** — *visar a* (= almejar) + feminino → *à*.  
12. **D** — *que* concorda com *eu*. A mistura; B *Mais de um* → sg.; C com *quem* clássico seria *organizou*; E indeterminação → *Precisa-se*.  
13. **C** — frase completa, formal, sem *isso* órfão.  
14. **C** — *ainda que* mantém concessão.  
15. **B** — *Houve* sg. + restrição sem vírgula indevida.
